# mneme-core

Core models, capability detection, and configuration for mneme-memory.

## Key Types

- `MemCell`: The fundamental memory unit (content, embedding, emotional valence, metadata)
- `SearchResult`: A retrieval result with score, source, and metadata
- `Link`: A typed connection between memories (7 types)
- `Capability`: Plugin resource requirements declaration
- `Tier`: Hardware capability level (S/A/B/C)
- `MnemeConfig`: Global configuration
